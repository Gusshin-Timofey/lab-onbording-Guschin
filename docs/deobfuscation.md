1. Расшифрованная строка (Base64):
import os; os.system('rm -rf /')


2. Анализ угрозы: Команда rm -rf / пытается рекурсивно и принудительно удалить все файлы и каталоги, начиная от корневого каталога системы. Запуск этого кода с правами администратора (root) приведет к полному уничтожению операционной системы и потере всех данных без возможности восстановления.

3. Методы защиты:
	• Запрет опасных функций: Полностью исключить использование динамической интерпретации строк через exec() и eval().
	• Статический анализ (SAST): Настроить линтеры и сканеры безопасности (например, bandit), которые автоматически блокируют код, содержащий вызовы exec или base64.b64decode.
	• Принцип наименьших привилегий: Запуск приложений от имени несистемных пользователей с ограниченными правами записи на диск.
